# Contributing

SWE OS is primarily Tommy's. It's public so you can learn from it and point your agents at it.

- **Issues are welcome.** A wrong or outdated fact, a broken link, or an agent that did something dumb because of SWE OS. Use the templates.
- **Small fixes can be PRs.** Typos, dead links, and outdated facts with a source. For anything bigger, like a new rule, skill, or guide, open an issue first. The answer may be no, because the opinions here are Tommy's.
- **Every PR runs the same checks.** Run `npm ci` once (it turns on the pre-commit secret scan), then `npm run check`. Never commit a real key, email address, or anything private.
