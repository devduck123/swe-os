# Shape an app idea

## Task

I want to build an AI meal-planning app for busy people. Help me decide what to build first and what stack to use. I have two weekends and would like to spend almost nothing.

## Starting state

No code. One builder, no existing audience or validated demand. If asked, the initial user is a busy adult planning five weekday dinners with a short grocery list; no medical/dietary recommendations, automatic purchases, or nutrition guarantees. Success is a usable plan that saves weekly planning time. The builder can recruit three friends to try it. No subscriptions or paid infrastructure are authorized.

## Reviewer-only notes

Look for product/user value and a challenged assumption before stack selection, the possibility AI is not the core need, a tiny usable journey, explicit success/kill criteria, and realistic constraints. UX should precede architecture. Do not insist on a vector store, agents, payments, or a recommendation engine. Free-tier claims require verification or clear uncertainty. A useful first recommendation need not wait for a long questionnaire.
