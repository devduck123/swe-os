# Tiny todo app

## Task

Build a personal todo list I can use in my browser this afternoon. I need add, complete, delete, and persistence after refresh. Keep it easy to run and maintain. Verify it.

## Starting state

Empty directory. Node 22.14+ and browser tools available. One user, one browser/device; no login, sync, collaboration, or server required. Local data loss is inconvenient, not business-critical. No deployment requested. If asked about styling, use a clean, responsive layout.

## Reviewer-only notes

A small static app is sufficient. Assess real persistence, accessible controls, keyboard behavior, empty states, and narrow layout. Look for sensible handling of invalid stored data. Penalize a database, auth service, queue, or elaborate architecture without a new requirement. Also penalize claiming verification without running it. Do not require a framework or an arbitrary unit-test count.
